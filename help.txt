SETUP VPS HELP

Cach chay:
  sudo bash setup.sh

Menu:
  1) Cap nhat he thong va cai dat goi can thiet
     Chay apt update, apt upgrade va cai ufw, ca-certificates, curl, gnupg.

  2) Cai dat Docker
     Cai Docker Engine va Docker Compose plugin neu may chua co docker.

  3) Cau hinh firewall (ufw)
     Gioi han OpenSSH, mo port 80/tcp va 443/tcp, sau do bat ufw.

  4) Tao user moi
     Kiem tra user da ton tai hay chua. Neu chua ton tai thi tao user moi va bat dat password.

  5) Tao/cap quyen sudo cho user
     Dam bao user ton tai, co password hop le va nam trong group sudo.

  7) Help
     Hien thi noi dung file help.txt.

  8) Cai authorized_keys cho user
     Doc file authorized_keys nam cung thu muc voi setup.sh, kiem tra user ton tai,
     tu choi neu file rong hoac sai cau truc key SSH, tao thu muc .ssh trong home
     cua user, copy authorized_keys, set quyen 700/600, sau do xoa file
     authorized_keys trong repo neu cai dat thanh cong.

  9) Harden SSH login
     Ghi config SSH de tat login bang username/password va chan root login.
     Dam bao sshd_config include file hardening va kiem tra effective config
     bang sshd -T truoc khi reload SSH. Kiem tra user se dung SSH key co
     authorized_keys hop le truoc khi reload SSH. Nen cai authorized_keys cho user sudo truoc khi chay option nay. Neu
     reload SSH thanh cong, script se schedule rollback bang systemd trong 60
     giay va yeu cau thu dang nhap SSH lai. Bam y de giu config moi. Bam n thi
     rollback roi quay lai menu. Khong xac nhan trong 52 giay thi tu rollback
     va thoat script. Neu SSH session hien tai bi mat, systemd van giu rollback.
     Canh bao:
     neu dang login bang username/password hoac SSH truc tiep vao root, viec vao
     lai server se la khong the. Sau khi chay function nay, ban co the phai dang
     nhap lai SSH. Chon no de huy va quay lai menu.

  10) Go user khoi group sudo
     Kiem tra user ton tai va dang nam trong group sudo, sau do go user khoi
     group sudo bang gpasswd hoac deluser.

  11) Cai ufw-docker (chan Docker bypass UFW)
     Yeu cau Docker va UFW da duoc cai san. Download script ufw-docker (pin theo
     commit) ve /usr/local/bin/ufw-docker, chay 'ufw-docker install' de patch
     /etc/ufw/after.rules va /etc/ufw/after6.rules, sau do reload UFW. Sau buoc
     nay container co port -p se khong tu dong expose ra Internet; muon mo phai
     dung 'ufw-docker allow <container> <port>'.

  12) Quan ly UFW rules (allow/deny/delete/list)
     Submenu cho phep allow rule (vd: 8080/tcp, 80:90/udp, 'from 10.0.0.0/8 to
     any port 22'), deny rule, xoa rule theo so (sau khi xem 'ufw status
     numbered'), va list rules. Yeu cau UFW da duoc cai dat.

  13) Quan ly ufw-docker rules (allow/delete/list)
     Submenu cho phep mo port cua mot container ra Internet
     ('ufw-docker allow <container> <port>'), xoa rule allow cho container
     (de trong port = xoa het), va list rules ('ufw-docker status'). Yeu cau
     option 11 da chay.

  14) Cai CrowdSec + firewall bouncer (bao ve SSH)
     Them CrowdSec repository qua install.crowdsec.net, cai crowdsec va
     crowdsec-firewall-bouncer-iptables. CrowdSec tu detect openssh-server va
     enable parser sshd; bouncer auto-register voi agent va enforce decision
     bang iptables. Sau buoc nay, brute-force SSH se bi block tu /var/log/auth.log.
     Neu fail2ban dang chay, in canh bao de tranh xung dot. Kiem tra bang:
     'cscli collections list', 'cscli decisions list', 'cscli metrics'.

  15) Them CrowdSec acquis nginx tu Docker container
     Yeu cau option 14 va Docker da chay. Hoi ten container, cai collection
     crowdsecurity/nginx, ghi acquis file
     /etc/crowdsec/acquis.d/docker-nginx-<container>.yaml (source: docker,
     labels: nginx) roi reload crowdsec. Container chua chay van OK, CrowdSec
     se cho. Co the chay nhieu lan voi container khac nhau.

  0) Thoat
     Thoat script.
